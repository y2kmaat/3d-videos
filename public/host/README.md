# Host media

Put your realistic host files here (see docs/realistic-host.md):

- `host-portrait.png`: Pixar-style still of you (used when `host` = "portrait")
- `host-talking.mp4`: talking-head clip with your voice (used when `host` = "video")
- `host-avatar.glb`: realistic rigged 3D avatar with ARKit blendshapes (used when `host` = "glb")

These are git-ignored by default so personal photos and videos aren't committed.
